# 拿不到聊天记录怎么办

## 电脑 QQ：官方导出 txt（最推荐）

1. 在电脑上登录 QQ，打开左下角菜单 → **消息管理器**（有的版本叫「消息记录」）。
2. 左侧选中要导出的好友/群，右上角「…」或右键 → **导出消息记录**。
3. 类型选 **文本文件（.txt）**，保存。
4. 导出的文件大致长这样：

```text
---- 2023-11-18 ----
[17:03:21] 林知夏：在吗
[17:04:02] 我：在
[17:04:10] 林知夏：今天好累啊
```

把文件拖进 Q伴 的「用聊天记录培养」即可。几千条就够，不必导出全部。

## 手机 QQ

手机端没有直接的 txt 导出；「聊天记录备份」只能恢复到另一台手机，不能读。
可行的替代：

- **长按复制**少量有代表性的消息，粘贴进 Q伴（几十句也能跑，统计会弱一些）；
- **凭印象写几句**：在培养页点「没有记录？凭印象写几句」，填说话方式、口头禅、一两句原话，
  模型先出草稿，再靠两轮反馈改。信息少时它会写得更克制，不会硬编背景。

## 不要做的事

- 不要为了导出聊天记录去装来历不明的「QQ 记录导出/解密」工具——大多要 root、要账号密码，
  记录里还有对方的隐私；
- 不要把导出的文件上传到网盘或在线转换站；本项目的解析和生成都在本地/你自己配置的模型接口里完成。

## 解析失败怎么办

- 如果提示「没有识别到消息」，确认是上面那种「日期行 + [时间] 昵称：内容」的格式；
- 如果只识别到一部分，页面会显示「另有 N 行没认出来」，可以继续用，也可以换文件；
- 群聊记录也能用，选「哪个是角色本人」时选目标角色即可。

## 数据去向

- 原始聊天记录只存在于当前页面的内存里，不上传、不落盘；
- 生成草稿时，统计结果和抽样原话会发送给你配置的文本模型；
- 定稿后只保存角色卡和统计摘要，不保存完整聊天记录。
