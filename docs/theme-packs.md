# 主题包：笺页 的 JSON 主题，不是 QQ 主题包

## 是什么

笺页 的主题包是一个 JSON 文件，里面存：

```json
{
  "app": "qpersona-theme",
  "version": 1,
  "theme": "light",
  "appearance": {
    "fontScale": "normal",
    "bubble": "sakura",
    "textStyle": "default",
    "chatBackground": "data:image/jpeg;base64,..."
  }
}
```

包含：浅色/深色、字号、气泡配色、气泡文字字体、聊天背景（图片以 dataURL 内嵌）。
「设置 → 外观 → 导出主题 / 导入主题」就能分享或换回来。

## 为什么不直接导入 QQ 主题包

- QQ 手机主题包是腾讯的私有格式（资源包 + 配置 + 校验），结构和字段都不公开；
- 里面的素材、字体、图标版权归腾讯，笺页 不能直接解析、分发或复用整套资源；
- 硬兼容会带来解析、加密和版权风险，收益也不大。

**能做的**：把 QQ 主题包里的背景图另存为图片，然后在 笺页 里当聊天背景/主页封面用——
这条路径现在就能走（设置 → 外观 → 聊天背景 → 上传）。

## 导入失败怎么办

- 只接受 `app: "qpersona-theme"` 的 JSON；
- 图片会内嵌在文件里，包可能比较大（几 MB），属于正常；
- 导入只改外观，不动角色、聊天记录和 API 配置。
