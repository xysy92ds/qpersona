# 角色广场：静态 JSON + 云端上传

> 状态：v0.23.0。静态广场已支持；云端广场上传已支持（**自动通过**，管理员审核界面未做）。

## 现在是什么

广场有两条读取路径，前端在「添加朋友 → 广场」里可以切换：

| 来源 | 数据 | 谁能写 |
| --- | --- | --- |
| 内置/静态广场 | `public/plaza/cards.json`，或右上角「地址」填的任意静态 `cards.json` | 维护者合并 JSON / 对方自己托管 |
| 云端广场 | Cloudflare D1 的 `plaza_cards` 表，经 `/api/plaza/cards` 读取 | 登录用户上传，当前**自动通过** |

两边都支持搜索、标签筛选、热门/最新排序和一键导入；区别是云端广场任何人登录后都能提交，
静态广场只能由维护者合并或对方自备一份 JSON。

## 云端上传（已支持）

- `GET /api/plaza/cards`：公开读取已通过的卡（服务端最多 200 张，前端按 100 张拉取）；
- `POST /api/plaza/cards`：**需登录**，上传后状态直接 `approved`，立即出现在广场；
- `GET /api/plaza/mine`：看自己的投稿和状态；
- `DELETE /api/plaza/cards/:id`：作者本人可删；部署时配了 `ADMIN_KEY` 的话，管理员也能删；
- 上传只带白名单展示字段 + 224px 小头像，**不上传主页背景/原图**；
  请求体超过约 850KB 会在本地直接提示（服务端上限约 900KB）；
- 广场卡单独存表，不随 30 天不活跃清理删除。接口细节见 [cloud.md](cloud.md)。

「我的投稿」在广场上传面板里显示每张卡的公开状态，并支持作者删除。

## 还缺什么（未支持）

- **管理员审核**：没有审核队列/界面，上传即公开；目前只有 `ADMIN_KEY` 的删除接口；
- **举报入口、限流、验证码、敏感内容过滤**都没有；
- 没有点赞/下载计数（静态 JSON 里的 `downloads` 只是展示字段）。

公开上传必然面临 NSFW、恶意提示词和隐私内容的风险，详见 [cloud.md](cloud.md) 的注意事项。

## 数据格式

静态 `cards.json`：

```json
{
  "version": 1,
  "cards": [
    {
      "id": "demo-zhixia",
      "author": "笺页",
      "uploadedAt": 1763827200000,
      "downloads": 128,
      "avatar": "https://example.com/avatar.png",
      "qq": {
        "nickname": "知夏",
        "signature": "书店打烊了，猫还在营业",
        "interests": ["书", "猫"],
        "aliases": ["知夏", "夏夏"]
      },
      "card": {
        "name": "林知夏",
        "description": "……",
        "personality": "……",
        "first_mes": "……",
        "mes_example": "……",
        "tags": ["日常", "慢热"]
      }
    }
  ]
}
```

- `card` 按 SillyTavern V2 字段；只保留白名单字段，`extensions` 不会从广场合并；
- `avatar` 只接受 `http(s)` 或 `data:image/`；
- 静态广场单次最多加载 200 张，字段会截断，坏条目直接丢弃。

## 几种分享方式

1. **云端上传**：登录后在广场直接提交，自动通过，适合公开分享（需要部署了云端 API）；
2. **合并到内置广场**：导出角色卡 → 提 Issue / PR 给维护者 → 合并进 `cards.json` → 重新部署；
3. **自己开一个广场**：把 `cards.json` 放到 GitHub Pages / Cloudflare Pages / 任意静态空间，
   在「广场地址」里填链接，别人也能用这个地址；
4. **直接发文件**：角色卡 JSON 发给朋友，对方在「添加朋友 → 导入」里选文件。

## 想要更完整的治理怎么办

至少需要一个共享写入点（云端广场已经是）：Supabase（Postgres + Storage + Auth）或
Cloudflare D1 + Worker / Pages Functions 都可。要补的是：

- 审核队列或「先审后发」开关，管理员界面；
- 登录 + 限流 + 举报入口，不要在前端放管理员 Key；
- 上传内容的敏感词/体积/格式校验。

## 安全与隐私

- 广场只渲染文本，Vue 默认转义 HTML，不执行卡片里的脚本；
- 导入前会展示设定和开场白，第三方卡的提示词由作者提供，自己判断；
- 云端上传是自动通过的，看到可疑卡片应有删除/举报预期，但目前没有举报按钮；
- 不要把聊天记录、API Key、真实联系方式放进公开卡片。
