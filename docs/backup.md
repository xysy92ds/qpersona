# 备份：导出的 JSON 里有什么

「设置 → 数据 → 导出数据」生成一个 JSON 文件，用于换机或留档。

## 包含

- 角色卡，以及每个角色的头像、主页背景、QQ 资料、兴趣、路由和开关；
- 所有会话、消息、记忆、表情包；
- 外观设置：主题、字号、气泡、文字风格、**聊天背景**；
- 个人资料：昵称、签名、**头像、主页背景**；
- 记忆总结频率、主动消息设置、广场地址、能力槽位绑定；
- 模型方案（名称、地址、模型、价格），**默认不含 API Key**。

## API Key

默认导出会清空 Key，导入后到「AI 设置」重新填一次即可。
如果只是自己换手机，可以在导出面板打开「包含 API Key」——但这样的文件等于账号钥匙，
不要发到群里、网盘或公开仓库。

## 导入

导入会**覆盖当前全部数据**（角色、聊天、设置、背景），所以先导出当前备份再导入。
导入完成后页面会自动刷新。

## 注意

- 背景、头像存的是 dataURL，备份文件可能很大（几 MB 到几十 MB），属于正常；
- 广场的卡片缓存不在备份里，只是一个地址；
- 如果导入后页面空白，先看控制台报错，再确认 JSON 的 `app` 是 `qpersona`。
