# 记忆：从“流水账”到可管理的记忆

## 结构

每条记忆有：类型、内容、重要度（1~10）、标签、来源（私聊/群聊）、创建时间、置顶。

- 类型：事实、偏好、关系、事件、约定、印象；
- 置顶：召回时优先，不参与自动降权；
- 来源：群聊总结的记忆会带 `[群聊]` 标记；
- 自动总结遇到相同内容会合并重要度和标签，不再重复追加；
- 「合并重复」按去掉标点和空白后的内容归并，保留最高重要度和全部标签。

## 角色记忆面板

角色资料 → 记忆 → 管理：

- 搜索内容/标签，按类型筛选，按重要度或时间排序；
- 手动添加、编辑、置顶、删除；
- 合并重复；
- 显示来源和重要度条。

## 召回

关键词二元组 + 重要度 + 类型加成 + 置顶加成，取前 7 条注入提示词。
群聊设置里可以关闭「私聊记忆进群」，只召回群聊来源的记忆。
